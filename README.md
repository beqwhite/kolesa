# Курс приёма (kolesa)

Веб-приложение (PWA) для отслеживания курса приёма таблеток с локальным хранением данных.

🔗 **Рабочая версия:** [beqwhite.github.io/kolesa](https://beqwhite.github.io/kolesa/)

## Функционал

* **Правило «6 утра»:** сутки длится с `06:00` до `05:59` следующего дня — ночной приём (например, в 02:00) засчитывается за текущий день курса, а не за следующий.
* **Суточный таймлайн (36 часов):** визуальная шкала времени с бегунком текущего момента и отметкой полуночи.
* **Адаптивная кнопка приёма:** меняет статус и действие в зависимости от текущей фазы цикла (приём / перерыв / уже принято).
* **Интерактивный календарь:** подсветка дней приёма и перерыва, ручная отметка или снятие приёма по клику на дату.
* **Учёт упаковки:** подсчёт остатка таблеток в пачке и напоминание о покупке новой.
* **Настройки и бэкап:** изменение длительности приёма (по умолчанию 21 день), перерыва (7 дней), размера упаковки, а также экспорт/импорт прогресса в виде текстового кода.
* **Автономная работа:** данные хранятся в `localStorage`, а `Service Worker` обеспечивает работу без интернета.

## Логика работы

```mermaid
flowchart TD
    A[Нажатие на кнопку приёма] --> B{Время меньше 06:00?}
    B -- Да --> C[Засчитать за предыдущую дату]
    B -- Нет --> D[Засчитать за текущую дату]
    C --> E{Фаза цикла}
    D --> E
    E -- Приём --> F[Сохранить отметку в localStorage]
    E -- Перерыв --> G[Статус «Сейчас перерыв»]
    F --> H[Обновить календарь, счётчик дней и остаток]
